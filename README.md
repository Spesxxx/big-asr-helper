# Big ASR 标注助手（17 语种 SOP Chrome 扩展）

面向 `aidp.byteintl.com` Big ASR 测试集标注任务的**零依赖、纯前端 Chrome 扩展（MV3）**。已内置云端多模态音频 API 配置，**无需安装 Python / ffmpeg / 本地服务**，解压即可分发给同事长期复用。

## 一、安装方式（同事 30 秒上手）

1. 将整个 `extension/` 文件夹（或压缩包解压后的目录）放到电脑任意位置（不要删除）。
2. 打开 Chrome 浏览器，地址栏输入：`chrome://extensions/`
3. 打开右上角 **「开发者模式」**。
4. 点击左上角 **「加载已解压的扩展程序」**，选择 `extension/` 目录即可生效。

## 二、日常使用流程

打开任意标注任务页（`https://aidp.byteintl.com/management/paas/task-v2/*/mark-v3/*`），页面右侧会自动出现 **「🎙️ Big ASR 助手」** 悬浮面板（可点击右下角 `🎙️ ASR 助手` 按钮收起/展开）：

1. **① 听音预标 ASR-text & 对比 `ref_text`**
   - 自动拉取当前题音频并结合 `ref_text` 进行听音校正（严格遵循 SOP 第 4 节：无标点、无阿拉伯数字、大段英文自动标记 `***`）。
   - 面板高亮展示词级 Diff 与异常时间段建议（可一键填入 `general_remark`），并自动回填 `ASR-text`。
2. **② 生成推荐 ITN & 第 5 节规则体检**
   - 自动点击平台原生 `Generate recommended ITN from ASR`，并按 SOP 第 5 节检查 `[source|output]` 语法、半角符号、标点外置、source 存在性及 1–10 数量词/序数词误转。
   - 人工复核无误后点击 `Confirm Latest ASR`。
3. **③ 强制对齐切分 & 回填时间轴**
   - 基于已确认的 `ITN-text` 与音频波形，结合云端多模态对齐 + 浏览器端 Web Audio 静音能量吸附，自动按完整句 / ≤20s 自然停顿 / 结尾半句规则切分；
   - 自动清空旧片段、在波形上拖拽生成新 `utterances` 并填入 100% 无损覆盖 `ITN-text` 的文本。
4. **④ 第 12 节提交前全检**
   - 一键执行全量硬校验（≥100ms、无重叠、不越界、按序拼接 100% 还原 `ITN-text`、标签合法性等）。
   - 人工逐条点 `Play` 听音核对边界后，手动点击页面 **「暂存」** 或 **「提交」**。

## 三、安全与兼容说明

- **绝不自动提交 / 释放**：代码层硬拦截对「提交」「释放」按钮的自动点击，所有提交均由人工终审触发。
- **跨任务与跨语种兼容**：自动匹配 `task-v2/*/mark-v3/*` 全部任务与 17 语种，切换下一题自动刷新题目 ID、语种、音频与时长。
- **配置可覆盖**：默认 API 参数已内置在 `extension/config.js`，如需临时更换 Key / 模型或调整单段上限秒数，可点击面板右上角 `⚙️` 在本地覆盖保存。
