# Big ASR 标注助手（17 语种 SOP Chrome 扩展）

面向 `aidp.byteintl.com` Big ASR 测试集标注任务的**零依赖、纯前端 Chrome 扩展（MV3）**，支持**插件内一键自动覆盖更新与热重启**。

## 一、首次安装（只需做一次，以后全部插件内一键更新）

1. 下载并解压最新压缩包到固定文件夹（不要删除该目录）：
   https://github.com/Spesxxx/big-asr-helper/releases/latest/download/big-asr-helper-extension.zip
2. 打开 Chrome 地址栏输入 `chrome://extensions/` → 打开右上角 **「开发者模式」** → 点击 **「加载已解压的扩展程序」** → 选择里面的 **`extension/`** 文件夹。
3. **启用插件内一键自动更新（只需双击运行一次）**：
   - **Mac 同事**：双击解压目录里的 **`安装一键更新_Mac.command`**（如提示未验证开发者，右键 → 打开即可）；
   - **Windows 同事**：双击解压目录里的 **`安装一键更新_Windows.bat`**。

完成以上 3 步后，**以后发布任何新版本，标注页顶部会自动弹出提醒，直接点「⚡ 一键更新」即可自动覆盖文件并重启扩展生效，全程无需再手动下载解压！**

## 二、日常使用流程

打开任意标注任务页（`https://aidp.byteintl.com/management/paas/task-v2/*/mark-v3/*`），面板默认折叠在右上角不遮挡屏幕（可按住深色标题栏自由拖拽位置，点 `+` / `−` 展开折叠）：

1. **① 听音预标 ASR-text & 对比 `ref_text`**
   - 自动拉取音频、浏览器端自动压缩长音频并调用多模态模型听音校正（SOP 第 4 节：无标点、无阿拉伯数字、大段英文标记 `***`）。
2. **② 生成推荐 ITN & 第 5 节规则体检**
   - 自动触发平台原生 `Generate recommended ITN from ASR` 并按 SOP 第 5 节体检。
3. **③ 强制对齐切分 & 回填时间轴**
   - 严格执行 **>20 秒必须按句子/停顿切分**，结合波形静音吸附自动用原生鼠标拖拽生成全部 `utterances`（拖拽期间面板自动鼠标穿透不挡波形）。
4. **④ 第 12 节提交前全检**
   - 一键执行全量 SOP 硬校验，人工复听确认后手动点击页面 **「暂存」** 或 **「提交」**（代码层硬拦截自动提交/释放）。
